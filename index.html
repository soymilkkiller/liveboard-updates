1どこにある？

左のメニュー「👋 入場・フォロー表示」→ 下の方の「👑 ファンクラブ名簿」 LIVE BRIDGE で配信につないでいれば、来たファンクラブの人がレベル付きで自動でたまります。MC は何もしなくて大丈夫です

2使い方

  1. 見たい日を選ぶ 「今日来た人」＝今日の配信に来た人（もう帰った人も入ります）／「これまで全員」＝記録を始めてからの全員
  2. レベルで絞る（しなくても OK） 「Lv50」「Lv45–47」などの区切りを押す（いくつでも選べます）。「Lv 下限〜上限」に数字を入れると、その範囲も出ます。「全レベル」で元に戻ります
  3. 「📋 表示中の名前をコピー」 いま表に出ている人の名前が、1人1行でコピーされます。LINE やメモにそのまま貼れます
  4. 「⬇ 表に書き出す（CSV）」 Excel で開ける表になります。Lv・@ID・ユーザー名・前の @ID・備考・来た日数などが入っています

3知っておくこと

人数は「いま配信にいる人数」ではありませんその日（または、これまで）に来たファンクラブの人の合計です。いまの人数は上の「視聴者」を見てください
レベルはいちばん新しいものだけファンクラブのレベルは下がりません（切れても 1 コインのハートミーで戻ります）。だから最新のレベルだけを記録します。配信中にレベルアップすると、数秒で表も変わり「UP」が付きます
備考「@ID を変えた人かも」初めて見る人なのに、もうレベルが高い人です。@ID を変えた人かもしれません。同じ人が @ID を変えたと分かったときは「@ID 変更：@前 → @今」と出ます
入るのは TikTok から知らせが来た人だけ入場・コメント・ギフト・いいねで見えた人です。何もしないで見ているだけの人は、入らないことがあります
見られるのは、いまつないでいる団の分だけパソコンの負担はほとんどありません（重くなりません）

1なにを消すの？

OBS のブラウザソースと TikTok LIVE Studio の一時ファイル（キャッシュ） たまると配信がカクついたり、重くなったりします。ログイン・設定・シーンは消えません

2自動の掃除

LIVE BRIDGE を起動するたびに、自動で掃除します（はじめから ON）「🏠 ホーム」→「🧹 キャッシュ掃除」の「LIVE BRIDGE を起動したら自動で掃除する」で ON／OFF できます
そのとき開いているアプリは飛ばします配信中に LIVE BRIDGE を起動し直しても、OBS には触りません。結果はその下に「今回の起動時（12:03）：… 消しました」と出ます
おすすめの順番パソコンをつける → LIVE BRIDGE が起動（ここで掃除）→ OBS・LIVE Studio を開く

3手で掃除する（カクつくとき）

  1. OBS と TikTok LIVE Studio を閉じる 開いていると消せません。「● 起動中」と出ているときは、閉じてから「🔍 もう一度確認」
  2. 「🏠 ホーム」→「🧹 キャッシュ掃除」で「🧹 掃除する」を押す OBS と LIVE Studio は別々のボタンです。右の数字が、いまたまっている量です
  3. 「✓ ○○ MB 消しました」と出たら完了 OBS・LIVE Studio を開き直してください
